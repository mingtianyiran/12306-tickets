\# 候补订单售票排队系统（链式队列 C语言）

&#x20;## 项目介绍

&#x20;本项目使用\*\*链式队列\*\*模拟候补车票分配。

&#x20;- EnQueue：候补订单入队，新增订单加到队尾排队

&#x20;- DeQueue：队头订单出票成功，执行出队

&#x20;- DispatchTicket：发放余票，从队头依次分配车票，先来先服务

&#x20;## 环境

&#x20;C语言，标准C库 `stdio.h` `stdlib.h`
